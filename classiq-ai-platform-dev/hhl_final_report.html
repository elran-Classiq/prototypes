How the Quantum Answer Was Extracted

  1. Post-selection: Keep only statevector entries where indicator = 1 and estimator_var = 0. This leaves 2 entries (one per memory basis state).
  2. Undo C scaling: Divide each amplitude by C = 1/2³ = 0.125. The HHL circuit multiplied by C during eigenvalue inversion; dividing recovers the relative magnitudes of x.
  3. Global phase correction: Multiply by e^{iθ} where θ = 0.7854 rad, chosen so that A·x̂ aligns with b. The global phase is unphysical (unmeasurable), but necessary to produce a real-valued comparison vector.
  4. Normalize: Divide by the vector norm to compare directions. HHL outputs the direction of the solution, not its scale.
